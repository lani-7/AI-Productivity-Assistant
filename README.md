# Subnet Smart Tutor

BUILD REQUEST: SubnetAI — AI-Powered IPv4 Subnetting Tutor

Build a polished, fully functional web application called SubnetAI.

Tagline:

Simplify.Subnet.Connect

SubnetAI is an AI-powered educational networking platform designed to help students understand and practise IPv4 subnetting.

This is intended as a university engineering/technology project and should look and behave like a polished real-world product rather than a simple calculator.

1. PROJECT PURPOSE

The core problem is that students learning networking often struggle with:

IPv4 addressing

CIDR notation

Subnet masks

Network addresses

Broadcast addresses

Usable host ranges

Number of hosts

Number of subnets

VLSM

Traditional subnet calculators often provide the final answer without teaching the reasoning.

SubnetAI should solve this by combining a deterministic subnetting engine with an AI-powered networking tutor.

The application should:

Calculate subnetting results accurately.

Explain how the calculation was performed.

Teach subnetting concepts.

Generate personalised practice questions.

Identify and explain student mistakes.

Help users design VLSM networks.

Track learning progress.

The application should feel like:

A subnet calculator + networking tutor + AI study assistant.

2. TARGET USERS

Primary users:

Networking students

Students preparing for networking examinations

The application should be beginner-friendly but capable of handling intermediate and advanced subnetting concepts.

11. STEP-BY-STEP CALCULATION

Never stop at the final answer.

Add a prominent button:

🧠 Explain This Calculation

When clicked, show a step-by-step explanation.

Example:

Step 1 — Identify the CIDR

/26 means that 26 bits are allocated to the network portion.

Step 2 — Determine Host Bits

IPv4 has 32 bits.

32 - 26 = 6 host bits.

Step 3 — Calculate Total Addresses

2⁶ = 64 total addresses.

Step 4 — Calculate Usable Hosts

64 - 2 = 62 usable hosts.

The two reserved addresses are:

Network address

Broadcast address

Step 5 — Calculate Block Size

Subnet mask:

255.255.255.192

Block size:

256 - 192 = 64

Step 6 — Determine the Address Range

Network:
192.168.10.0

Usable:
192.168.10.1 – 192.168.10.62

Broadcast:
192.168.10.63

Make this explanation visually engaging.
